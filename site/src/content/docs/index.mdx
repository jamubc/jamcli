JamCLI is a coding agent that runs in your terminal. It works with local models through Ollama as
well as hosted providers, and it asks before it changes anything you have not allowed.

These pages explain how it works from the inside: what the model is told, where its tools come
from, and how to add one.

## How to read these pages

- **Every claim names its source.** A path with a symbol, like
  `src/core/runtime/prompt.ts · buildRuntimePrompt`, links to the code. The build fails when a named
  file or symbol no longer exists, so a page cannot quietly go stale. Line numbers are left out
  because they change with every edit.
- **Proofs are commands.** A green block gives a command to run from the repository root and says
  what it should show.
- **For language models:** [`/llms.txt`](llms.txt) indexes these pages, and
  [`/llms-full.txt`](llms-full.txt) is all of them as one plain-text file.
