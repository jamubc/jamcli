<Aside title="In short">
Each key does one named action. The table gives the default keys for each, taken from the
interface's definitions when the site is built. Rebind any action in `keybindings.json` in your
configuration directory.
</Aside>

<ReferenceTable table="keys" />

`keybindings.json` maps an action to a key or a list of keys:

```json
{ "cycle_mode": "ctrl+y", "history": ["ctrl+r", "ctrl+s"] }
```

The keys a question or a list uses (1 to 4, Up, Down, Tab, and Escape to close) are fixed, so they
read the same everywhere.
