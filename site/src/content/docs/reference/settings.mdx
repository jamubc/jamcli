<Aside title="In short">
Settings live in JSON files, read in layers: your own `config.json`, then the project's
`.jamcli/config.json`, then `.jamcli/config.local.json`, then environment variables, each layer
taking precedence over the ones before it.
`/config` and `jamcli config` read and change them. The table lists every setting in the
configuration schema, with the same words `/config` shows.
</Aside>

<ReferenceTable table="settings" />

A dotted key names a setting inside a group: `delegation.max_depth` is `max_depth` in the
`delegation` object. Your own file is `config.json` in `~/.config/jamcli/`, or in
`JAMCLI_CONFIG_DIR` when that is set. A key's own text, `api_key`, is left out here, as it is from
`/config`: store keys with `jamcli auth set` or name a variable with `key_env_var`.
