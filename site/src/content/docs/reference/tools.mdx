<Aside title="In short">
These tools are registered in every session. The description in each row is the text the model
reads when it decides whether to call the tool, taken from the tool's definition when the site is
built. The class is what the permission mode judges. Some tools are added only when a session
needs them, and are covered in [Where tools come from](../../concepts/tools/).
</Aside>

## Tools a session adds

`skill`, `search_tools`, `lsp`, and `web_search` are registered when their condition holds: skills
are installed, MCP servers bring many tools, a language server is available, or a search provider
is configured. Tools from MCP servers join the same registry.
