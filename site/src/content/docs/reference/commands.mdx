<Aside title="In short">
These are the built-in commands, in the order `/help` lists them. Each is defined once, and the
interface, headless runs, ACP, and MCP all run the same set. The table below is written from those
definitions when the site is built, so it lists exactly what the code defines.
</Aside>

<ReferenceTable table="commands" />

Arguments in square brackets are optional; arguments in angle brackets are required. `/help
<command>` explains one command in more detail.

Commands of your own, from files, plugins, or an MCP server's prompts, join this set in a session
and are not listed here.
